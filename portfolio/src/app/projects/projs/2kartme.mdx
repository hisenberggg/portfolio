<h2 id="what-i-built">What I Built</h2>

- **Simple login and signup** with profile photos powered by Django auth.
- **Product list and detail pages** with clear brand, price rules, and friendly cards.
- **Category and price filters** on the home page so shoppers can find items quickly.
- **Cart and checkout** that store items on the server and create `Order` records with status updates.
- **Order history** where users can review or cancel their own purchases.

<h2 id="how-it-works">How It Works</h2>

- Two Django apps split the work: `eshop` for shopping and `userauth` for accounts.
- Models for `Product`, `Order`, and `Profile` keep catalog data, cart state, delivery steps, and user images.
- Every store page uses `@login_required`, and Bootstrap templates keep the layout responsive.
- SQLite runs local demos, and settings can switch to PostgreSQL or MySQL. Media uploads land in `products/` and `profile_pics/` folders.
- A small jQuery script calls when add_to_cart and shows a toast when an item is added.
- **Admin tools** through the Django admin site for fast product and order edits without code.

<h2 id="implementation-notes">Implementation Notes</h2>

- The cart flips an `in_cart` flag on each product so checkout logic stays easy to read.
- Checkout reads quantities from a list, letting one request handle many line items.
- Order status choices (received, shipped, delivered, etc.) prepare the app for tracking updates.
- The filter form reads GET values, ignores bad input, and fills min/max boxes using `Min` and `Max` price queries.
- Profile records are created right after signup, giving each user an avatar slot from day one.

<h2 id="demo--usage">Demo & Usage</h2>
- **Video**: [Repository demo clip](https://github.com/user-attachments/assets/ebcd00e6-54de-4671-a311-d98108b82685)
- **Try it locally**: Clone the repo, create a virtual environment, install `requirements.txt`, run migrations for `userauth` and `eshop`, then start `python manage.py runserver`.
- **Admin access**: Create a superuser, visit `/admin`, and manage inventory, categories, and orders from the dashboard.
